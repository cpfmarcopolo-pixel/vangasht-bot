# ربات اینستاگرام وان گشت

این ربات هر روز از راه رسمی خود اینستاگرام (Instagram Graph API) روی پیج وان گشت این‌ها را منتشر می‌کند:

| ساعت (ترکیه) | چه چیزی |
|---|---|
| حدود ۱۰:۰۰ | استوری ۱: نرخ امروز از سایت (اگر نرخ‌های سایت قدیمی‌تر از ۳۰ ساعت باشند، به‌جایش یک استوری تبلیغاتی می‌رود) |
| حدود ۱۷:۰۰ | استوری ۲: استوری بعدی از `stories.json` |
| حدود ۲۰:۰۰ | پست: پست بعدی با کپشن از `posts.json` |

ساعت دقیق هر روز چند دقیقه جابه‌جا می‌شود تا رفتار پیج طبیعی‌تر باشد.

- محتوا: `posts.json` (۲۱ پست) و `stories.json` (۱۶ استوری). بعد از آخری، از اول تکرار می‌شوند.
- شمارهٔ واتس‌اپ، ساعت کاری و آدرس از خود سایت خوانده می‌شوند. اگر در پنل مدیریت عوضشان کنید، ربات هم عوض می‌کند.
- `state.json` نشان می‌دهد ربات به کدام پست و استوری رسیده و چه چیزهایی منتشر شده است.
- رمز دسترسی اینستاگرام فقط در **Settings → Secrets → IG_TOKEN** این مخزن است. آن را جای دیگری نگذارید.

انتشار دستی برای تست: **Actions → Vangasht Instagram bot → Run workflow**.
